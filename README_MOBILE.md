# DineWise Mumbai — Mobile App (Android + iOS) using Capacitor

This turns your existing **Vite + React (TS)** frontend into a native mobile app shell.

## What you get
- Same UI as the web app (no rewrite)
- Android Studio project + Xcode project generated by Capacitor
- Native app builds (APK/AAB, IPA)

## Important note about your backend
Your current `server.ts` runs an **Express API + SQLite**. A mobile app cannot rely on `localhost` on the phone.

✅ Best practice:
- **Deploy the backend** somewhere (Render/Fly/Railway/VPS)
- Set your frontend to call that deployed API base URL

If you want, I can help you split this repo into:
- `apps/web` (frontend)
- `apps/api` (backend)
so you can deploy the API cleanly.

## 1) Install dependencies

```bash
npm install
```

## 2) Build the web bundle (goes into `dist/`)

```bash
npm run build:web
```

## 3) Initialise Capacitor

```bash
npx cap init "DineWise Mumbai" com.dinewise.mumbai --web-dir dist
```

> You only need to do this once. (`capacitor.config.ts` is already included.)

## 4) Add platforms

### Android
```bash
npx cap add android
```

### iOS (macOS required)
```bash
npx cap add ios
```

## 5) Sync web build into native projects

```bash
npx cap sync
```

## 6) Open projects

### Android Studio
```bash
npx cap open android
```

### Xcode
```bash
npx cap open ios
```

## 7) Run on a device

### Android
- Connect phone (USB debugging ON)
- In Android Studio: Run ▶

### iOS
- Open Xcode project
- Select a real device / simulator
- Run ▶

## Common issues

### API calls fail on phone
- Ensure the API is reachable publicly (HTTPS)
- Update your frontend API base URL (don’t use `localhost`)

### Cleartext HTTP blocked (Android)
- Prefer HTTPS.
- If you must use HTTP in dev, enable cleartext temporarily in AndroidManifest.

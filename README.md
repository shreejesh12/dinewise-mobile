# DineWise

AI-assisted restaurant discovery and verified-review app for Mumbai.

## What it does

- Discover nearby restaurants with Google Places data
- Compare options and book tables
- Post verified reviews with images
- Earn rewards for contributions
- Admin dashboard with analytics

## Tech stack

- **Frontend:** React, TypeScript, Vite
- **Mobile:** Capacitor (Android/iOS packaging)
- **Backend:** Express + SQLite
- **Auth:** Firebase
- **APIs:** Google Places, Gemini (review verification)
